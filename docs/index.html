Get Started

Up and running
in 4 steps.

Requires macOS 15 (Sequoia) or later, Xcode 16+, and Homebrew.

1

Install yt-dlp

The download engine Fetch wraps. Install via Homebrew.

brew install yt-dlp
2

Clone the repo

Grab the source code from GitHub.

git clone https://github.com/twitchyvr/Fetch.git cd Fetch
3

Generate Xcode project

Fetch uses XcodeGen to manage the project file.

brew install xcodegen xcodegen generate
4

Build and run

Open in Xcode or build from the command line.

# Open in Xcode open Fetch.xcodeproj # Or build from CLI xcodebuild -scheme Fetch build
